# Curated screenshots

Playwright writes complete test captures to the ignored `frontend/test-results/screenshots/` directory. Normal test runs do not modify tracked screenshots. To intentionally refresh this small selection, start the backend and frontend test prerequisites, then run `npm run screenshots` from `frontend/`.

The selected captures are implementation screenshots for review, not Signal reference images. This checkout has no `docs/reference/` assets.
